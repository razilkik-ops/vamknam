# vamknam.by

Сайт мастерской именных подарков из дерева.

## Открыть на компьютере

Дважды нажмите `start.command`. Сайт откроется по адресу http://localhost:4318/.
Пока сайт нужен, оставляйте окно Терминала открытым. Остановить сервер: Ctrl+C.

Можно запустить вручную из папки проекта:

```sh
python3 -m http.server 4318 --bind 127.0.0.1 --directory dist
```

## GitHub Pages

Готовые файлы сайта находятся в `dist/`. Пути поддерживают публикацию в подпапке репозитория.
Workflow `.github/workflows/pages.yml` публикует `dist/` при изменениях ветки `main`.
В настройках репозитория выберите Settings → Pages → Source → GitHub Actions.

Фотографии, логотип и иконки хранятся отдельными файлами. Источники и промпты — `SOURCES.md`.
