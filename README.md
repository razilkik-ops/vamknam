# vamknam.by

Сайт мастерской изделий из дерева, обновлённый по предоставленным дизайн-референсам.

- Сайт: https://razilkik-ops.github.io/vamknam/
- Репозиторий: https://github.com/razilkik-ops/vamknam

## Запуск и сборка

```sh
npm ci
npm run build
npm run dev
```

Сборка создаёт 36 статических HTML-файлов, включая 404, и копирует JS/CSS из `src/reference-redesign/`. Хедер остаётся общим EJS-шаблоном `views/partials/header.ejs`; его оформление и боковая корзина сохранены из предыдущей версии. Исходный каркас стилей находится в `src/reference-redesign/site-shell.css`, оформление по новым референсам — в `src/reference-redesign/reference.css`, страницы и взаимодействия — в `src/reference-redesign/app.js`.

GitHub Actions выполняет `npm ci` и `npm run build`, затем публикует папку `dist/` в GitHub Pages. Ссылки, маршруты и ассеты используют общий `<base>` и поддерживают префикс `/vamknam/`.

## Страницы и заказ

Главная, каталог и категории, страницы изделий, «Как заказать», «О мастере», «Отзывы», «Контакты» и корзина. Старые адреса товаров и ссылки вида `/product/?id=...` продолжают работать.

Корзина сохраняется локально; сохранённые позиции предыдущей версии мигрируют в новый формат. Добавление товара открывает боковую панель. Количество, удаление, итог и страница корзины синхронизированы. Заявка подготавливается в браузере для самостоятельной отправки в Instagram; автоматической отправки и онлайн-оплаты нет.

## Изображения

Новые изображения созданы встроенным ImageGen отдельно: один объект — один вызов — один файл. Исходные PNG и описания генераций находятся в `reference-assets/redesign-20261118/`, веб-файлы — в `dist/assets/`. Каждая иконка и орнамент хранятся самостоятельным SVG. Дополнительные изображения ранее созданных страниц сохранены в `dist/assets/reference`, `process`, `contact`, `order` и `reviews`.

Фотографии воссозданы по скриншотам. Исходного видео нет — в галерее показан второй ракурс. Дизайны отмечены как визуализации; параметры, цена и срок уточняются у мастера. Телефон и Telegram в сохранённом хедере, а также самостоятельные страницы мастерской, отзывов и контактов сохранены из предыдущего проекта.

- 35 страниц и 404 создаются воспроизводимой сборкой.
