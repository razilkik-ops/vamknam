# Первый экран — новая композиция

`layout-reference.png` — цельный дизайн-референс, созданный встроенным ImageGen по скриншоту сайта. Из него не извлекались фотографии, иконки или декоративные элементы.

`hero-product.png` — отдельно созданная фотография одного изделия; веб-версия — `dist/assets/hero-crafted-20261118.jpg`. Изделие, крючки и ключи целиком находятся в кадре. Арочная форма задаётся CSS.

Полные промпты обеих отдельных генераций сохранены в `prompts.json`. Вёрстка находится в `src/reference-redesign/hero.css`, разметка — в `src/reference-redesign/app.js`. Общий EJS-хедер сохранён.
