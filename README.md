# vamknam.by

Сайт мастерской изделий из дерева. Вёрстка повторяет предоставленные пользователем референсы: главная, каталог ключниц, оформление заказа и подробная карточка ключницы «Листья». Изделия и цены выбраны пользователем по референсам.

- Публичный сайт: https://razilkik-ops.github.io/vamknam/
- Репозиторий: https://github.com/razilkik-ops/vamknam
- Локально: http://localhost:4318/

## Запуск

Дважды нажмите `start.command` в этой папке. Либо запустите:

```sh
python3 -m http.server 4318 --directory dist
```

Исходники статического сайта находятся в `dist`. Установка пакетов не нужна. `python3 build.py` создаёт все страницы из общей оболочки `dist/index.html`; это автоматически выполняют `start.command` и GitHub Actions перед публикацией `dist`.

## Страницы

Главная `/`, каталог `/catalog/`, заказ `/how-to-order/`, корзина `/cart/`, ключница `/product/klyuchnitsa-listya/`. Остальные карточки открываются по `/product/?id=...`. Все ссылки и ассеты поддерживают префикс GitHub Pages `/vamknam/`.

Корзина сохраняется локально в браузере. Форма составляет текст заявки: покупатель копирует и самостоятельно отправляет его мастеру. Онлайн-оплаты и автоматической отправки персональных данных нет.

## Дизайн и изображения

20 самостоятельных фотографий созданы отдельными вызовами встроенного ImageGen. Каждая иконка — отдельный SVG. Исходные PNG сохранены в локальной папке `reference-assets`; описания генераций — в `reference-assets/PROMPTS.md`, веб-версии — в `dist/assets/reference`. Изображения не извлекались из скриншотов. Фотографии являются реконструкциями, поэтому буквальное совпадение изображений с референсами не гарантируется.

Цены, телефон и условия самовывоза перенесены из предоставленных референсов. Для товаров, у которых на референсах нет цены, указано «По запросу». Устаревшие даты отправки из изображения заменены уточнением даты у мастера. Перед коммерческим запуском владелец может скорректировать эти данные в `dist/app.js`.
