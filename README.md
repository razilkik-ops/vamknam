# vamknam.by

Сайт мастерской изделий из дерева. Вёрстка повторяет предоставленные пользователем референсы: главная, каталог ключниц, оформление заказа и подробная карточка ключницы «Листья». Изделия и цены выбраны пользователем по референсам.

- Публичный сайт: https://razilkik-ops.github.io/vamknam/
- Репозиторий: https://github.com/razilkik-ops/vamknam
- Локально: http://localhost:4318/

## Запуск

Дважды нажмите `start.command` в этой папке. Либо запустите:

```sh
npm ci
npm run dev
```

Для сборки нужны Node.js 22+ и Python 3 для локального сервера. `npm ci` устанавливает EJS, `npm run build` создаёт 15 статических страниц из `views/layout.ejs`. Единственный шаблон шапки — `views/partials/header.ejs`; боковая корзина — `views/partials/cart-drawer.ejs`. `start.command` устанавливает зависимости при первом запуске и собирает сайт. GitHub Actions выполняет `npm ci` и `npm run build` перед публикацией `dist`. `python3 build.py` сохранён как совместимая команда сборки.

## Страницы

Главная `/`, каталог `/catalog/`, заказ `/how-to-order/`, о мастере `/about/`, отзывы `/reviews/`, контакты `/contacts/`, корзина `/cart/`, ключница `/product/klyuchnitsa-listya/`. Все пять пунктов меню ведут на самостоятельные страницы. Остальные карточки открываются по `/product/?id=...`. Все ссылки и ассеты поддерживают префикс GitHub Pages `/vamknam/`.

Корзина сохраняется локально в браузере. Форма составляет текст заявки: покупатель копирует и самостоятельно отправляет его мастеру. Онлайн-оплаты и автоматической отправки персональных данных нет.

## Дизайн и изображения

20 самостоятельных фотографий созданы отдельными вызовами встроенного ImageGen. Простые интерфейсные иконки хранятся отдельными SVG, три иллюстрации процесса — отдельными PNG. Исходные PNG сохранены в папке `reference-assets`; описания генераций — в `reference-assets/PROMPTS.md`, веб-версии — в `dist/assets/reference`. Изображения не извлекались из скриншотов. Фотографии являются реконструкциями, поэтому буквальное совпадение изображений с референсами не гарантируется.

Цены, телефон и условия самовывоза перенесены из предоставленных референсов. Для товаров, у которых на референсах нет цены, указано «По запросу». Устаревшие даты отправки из изображения заменены уточнением даты у мастера. Перед коммерческим запуском владелец может скорректировать эти данные в `dist/app.js`.

## Корзина и иконки

Иконка корзины со счётчиком присутствует в общей EJS-шапке на всех страницах. Добавление изделия открывает боковую корзину; количество, удаление и суммы синхронизируются со страницей корзины и локальным хранилищем браузера. На мобильных устройствах панель открывается снизу.

Три иконки блока «Как это работает» созданы отдельными вызовами встроенного ImageGen на прозрачном фоне. Каждый PNG хранится отдельно в `dist/assets/process`; исходники и промпты — в `reference-assets/PROCESS-ICONS.md`.

Иконки телефона, Telegram и Instagram в карточках контактов также созданы тремя отдельными вызовами ImageGen. Веб-файлы — `dist/assets/contact`, исходники и промпты — `reference-assets/CONTACT-ICONS.md`. Переключатель категорий каталога расположен над товарами.

Галерея карточки товара использует квадратные основные фотографии и миниатюры. Блок с кнопкой воспроизведения удалён; переключение ракурсов и увеличение фотографии сохранены. Кнопки имеют максимальное скругление, выбранная категория каталога выделяется обводкой.
